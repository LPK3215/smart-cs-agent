## 7.2 关键修正（基于真实代码重新核对）

重新通读源码后发现，初版逆向报告（第 0-6 章）有几处**误判**，在此更正：

1. **向量库不是字符哈希**：`vector_store.py` 实际使用 **DashScope `text-embedding-v3`** 真实 embedding + FAISS `IndexFlatIP`（余弦相似度），并有"embedding 失败→关键词回退"降级。初版报告误读为字符哈希，特此更正。（README 原描述正确。）
2. **LangChain 版本**：代码用 `from langchain.agents import create_agent`，这是 **langchain 1.x 稳定 API**，非"实验性"。`requirements.txt` 原为 `>=0.3.0` 会装到无此 API 的旧版，已修正为 `>=1.0.0`。
3. **README 与代码一致性**：重新核对后，**README 描述与代码基本一致**（FAISS/DashScope、5 工具、bcrypt、aiosqlite、8 表、三级护栏 23 模式）。初版报告"README 与代码不一致"清单中的 Chroma/passlib/sqlite3 三项**不成立**，予以撤销；工具数量 5 个与 README 一致。仅"生产级暗示"属定位措辞问题，已通过 README 补充部署章节弱化。
4. **速率限制已存在**：`.env` 有 `RATE_LIMIT_PER_MIN`，`main.py` 的 `/chat` 与 `/chat/stream` 均调用 `check_rate_limit`（429）。初版报告"无速率限制"属误判，已更正。
