## 0.2 项目定位（从代码反推设计意图）

项目的核心叙事是：**用 LLM Agent 替代传统固定话术客服**，并刻意做出"可观测、可审计、可降级"的工程化样板。作者明显在追求一个**教学展示友好、但架构上按可生产化思路设计**的系统：

- Agent 自主决策调用 5 个工具（不是 prompt 套壳）
- RAG（FAISS）增强 FAQ 回答
- SSE 流式 + 工具调用轨迹可视化（前端打字机 + 进度）
- 三级 Guardrails（注入/安全/输出）
- 长短期记忆 + 用户画像
- 工具审计表 + 管理员仪表盘

意图：作为"AI 客服 Agent 范式"的参考实现（reference implementation），而非某个具体企业的生产系统。
