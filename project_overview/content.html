Project Overview

Smart CS Agent is a full-stack intelligent customer service platform built with modern web technologies and AI agent architecture.

AI
ReAct Agent Engine
LLM autonomously decides which tools to invoke, in what order, and when to transfer to human agents. Powered by LangChain with DeepSeek LLM integration.
RAG
Vector Semantic Search
DashScope text-embedding-v3 + FAISS vector store for semantic FAQ retrieval. Cosine similarity threshold filtering with keyword fallback.
SSE
Streaming Response
Real-time SSE streaming with token-level output, tool call progress feedback, and full reasoning trace visibility for end users.
DB
Cross-Session Memory
Long-term memory extraction on session close, user profile aggregation, and context injection for personalized multi-turn conversations.
Shield
Three-Tier Safety
BLOCK/WARN/SAFE severity levels with 23 injection and content safety patterns covering both Chinese and English attack vectors.
Admin
Admin Dashboard
Dedicated admin panel with analytics charts, tool audit logs, session management, intent distribution, and satisfaction tracking.

System Architecture

Three-tier separation: User Portal, FastAPI Backend with Agent Engine, and Admin Dashboard.

1
User Request
User sends message via Vue 3 frontend with JWT token. Request passes through CORS middleware to FastAPI backend.
2
Safety Check
Input passes three-tier guardrails: empty/length validation, injection pattern detection (BLOCK/WARN), and content safety filtering.
3
Agent Reasoning
ReAct Agent autonomously decides which tools to invoke. Multi-model routing selects light or full LLM based on input complexity.
4
Streaming Response
SSE event stream delivers tokens, thinking feedback, tool call progress, and final metadata. Frontend renders Markdown with syntax highlighting.

Core Features

Deep dive into the key capabilities that make Smart CS Agent production-ready.

⚡ ReAct Agent with Autonomous Tool Calling

The LLM independently decides which tools to invoke, in what order, and whether to chain multiple tools. The system prompt provides 6 decision rules guiding tool selection, with a maximum of 10 ReAct iterations per request. Multi-model routing automatically selects a lightweight model for simple queries and a full model for complex ones.

search_faq
Vector semantic search (RAG) with FAISS + DashScope embedding, keyword fallback. Returns similarity score for confidence calibration.
query_order
Order status and logistics tracking via service abstraction layer. Timeout-protected with 30s limit.
check_refund
Refund eligibility check and status query by refund ID or order ID. Returns ETA and processing details.
troubleshoot
Technical issue diagnosis for crash, login, payment, and performance problems. Structured solution output.
transfer_to_human
Seamless handoff to human agents with reason tracking. Auto-triggered for safety violations.
🛡 Three-Tier Safety & Guardrails

The guardrails system operates at three severity levels and covers 23 distinct safety patterns. BLOCK-level violations immediately reject the request. WARN-level patterns are logged but allowed through for monitoring. SAFE indicates no issues detected.

Injection BLOCK (11)
English: ignore instructions, role hijack, disregard rules, reveal prompt, ask instructions
Chinese: 忽略指令, 角色扮演, 泄露提示词, 无视规则
Special: ChatML tokens, encoding tricks
Injection WARN (4)
English: jailbreak ref, repeat prompt
Chinese: 越狱模式, 复述提示词
Content BLOCK (4)
English: bomb making, CSAM
Chinese: 制造炸弹, 儿童色情
Content WARN (4)
English: self-harm, cybercrime
Chinese: 自杀方法, 黑客攻击
⏳
Sliding Window Memory
Recent 8 messages kept in full context. When history exceeds 16 messages, LLM automatically generates a summary stored in the session record for efficient context compression.
💾
Cross-Session Memory
On session close, key memories are automatically extracted: issue types, transfer signals, and session summaries. Stored in user_memories table for injection into future sessions.
📈
User Profiles
Aggregated user statistics: total sessions, message count, intent distribution, average rating, and transfer rate. Profile data enriches system prompt for personalized responses.

Upgrade Roadmap

Six-layer architecture upgrade plan with current completion status.

1. Input Preprocessing 95%
  • 1.1 Enhanced prompt injection detection (23 patterns, 3-tier)
  • 1.2 Expanded sensitive word library with tiered handling
  • 1.3 IP-level rate limiting
2. Context & Memory 95%
  • 2.1 Vector semantic retrieval (RAG) with FAISS + DashScope
  • 2.2 Cross-session long-term memory
  • 2.3 User profile aggregation layer
  • 2.4 Structured key fact extraction in summaries
3. Agent Reasoning 98%
  • 3.1 Multi-model routing (light/full model)
  • 3.2 User feedback during reasoning (thinking events)
  • 3.3 Dynamic system prompt with current time injection
  • 3.4 Secondary verification of tool call results
4. Tool Layer 90%
  • 4.1 Service abstraction layer (Protocol + mock/real switch)
  • 4.2 Knowledge base vectorization + RAG
  • 4.3 New tools: create_ticket, send_notification, query_account, apply_coupon
  • 4.4 Tool call timeout and retry mechanism
5. Output Processing 90%
  • 5.1 Real-time safety filtering for streaming output
  • 5.2 Response formatting enhancement (Markdown)
  • 5.3 Confidence-driven response strategy
6. Persistence & Observability 95%
  • 6.1 Database connection pool + WAL mode
  • 6.2 Structured logging system
  • 6.3 Enhanced health check endpoint
  • 6.4 Data archival strategy
